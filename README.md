# hello_world

A simple Express.js HTTP server with two endpoints.

## Endpoints

| Method | Path       | Response         | Status | Content-Type |
|--------|------------|------------------|--------|--------------|
| GET    | `/`        | `Hello, World!\n`| 200    | text/plain   |
| GET    | `/evening` | `Good evening`   | 200    | text/plain   |

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the server

```bash
npm start
```

The server runs at [http://127.0.0.1:3000/](http://127.0.0.1:3000/).
